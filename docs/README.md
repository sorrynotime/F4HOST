## 当前结论

- 已实现：一个接收器、一个接口、一个 Interrupt IN 端点的数据采集；支持范围内的标准 HID 字段解析。
- 已验证：Cortex-M4 C 编译、Arm Compiler 6 链接及 HEX 生成、解析器和 Host 模拟测试。
- 待实机确认：KP50 代际、VID/PID、接口、输入包、无线状态以及是否需要厂商握手。

文档中的“协议通用知识”“源码行为”“官方资料结论”和“实机待确认项”分别标明。`usb_ready` 不能作为手柄无线在线的判据。

## 后续更新规则

1. 收到设备描述符或抓包后，在第 02 篇补充型号、模式、固件版本与证据；不要只写一组无来源的偏移。
2. 修改解析或状态语义时，同步第 03 篇；修改接线或日志时，同步第 04 篇。
3. 重新验证后，在第 05 篇注明日期、工具链和覆盖范围。没有上板验证的条目继续标为待确认。
