## 已核对的官方资料

查阅日期：2026-09-14。来源是上一轮实际访问的官方页面，本次整理没有重新检索网络。

- [北通官方产品说明书入口](https://community.betop-cn.com/#/)：列有鲲鹏50初代、第二代及联名款，版本不能混为一谈。
- 官网链接的[鲲鹏50初代电脑连接教程](https://www.yuque.com/fujuan-us0ly/ixqxx4/bzl7zbyo4h7m1644)：接收器插入 USB 后，打开手柄，长按 HOME 进入菜单，选择「模式切换 → PC」。页面中的 Xbox wireless controller 是蓝牙连接说明，不能拿来证明 USB 接收器的协议。

这些资料没有给出 USB 报告描述符、VID/PID、输入包定义或接收器初始化命令。本版因此通过设备枚举结果选择路径，不发送猜测的模式切换、震动或厂商命令。

## 适配顺序与完成条件

1. **识别接收器**：记录完整型号、模式、VID/PID、接口与端点；能够复现枚举结果。
2. **获得输入**：区分标准 HID 与厂商接口。若只有描述符没有输入，先确认配对与接口，再核查初始化需求。
3. **确定物理映射**：单独测试按钮、方向帽、各轴和扳机，建立有证据的字段表，不把搜索结果中的其他型号格式直接套入。
4. **确定生命周期**：验证按下/松开、复位、拔插、无线失联和重连，不残留旧控制状态。
5. **增加专用适配**：只有完成以上核对后，才按 VID/PID、接口特征、版本等增加特定协议处理。

当前完成的是首版软件基础和软件测试；上述实机完成条件均尚未验收。
